## 🌍 The Problem & The Solution
Historical training datasets often contain hidden demographic proxies (e.g., zip codes masking race or income). When enterprise AI models ingest this flawed data, they learn and amplify systemic discrimination in automated decisions like hiring and loan approvals.

**Lexi-Fair AI** is a "Shift-Left" Contextual Proxy Scanner. We allow data scientists to seamlessly upload datasets, detect intersectional bias using LLMs, and automatically quarantine risky proxies *before* the data ever touches a machine learning model. 

**Targeted UN Sustainable Development Goals (SDGs):**
* 👩‍💻 **Goal 5:** Gender Equality
* 📉 **Goal 10:** Reduced Inequalities
* ⚖️ **Goal 16:** Peace, Justice and Strong Institutions

---

## ✨ Key Innovations (Why We Win)
* **Zero-Data Auditing:** Traditional tools crunch millions of rows of sensitive PII. Lexi-Fair predicts bias instantly using only dataset schemas and the Target Variable.
* **Privacy-First Governance:** Because we only analyze headers and structural footprints, enterprise datasets never leave the local browser, eliminating data breach liabilities.
* **Root-Cause Interception:** We use Gemini's semantic reasoning to catch non-obvious social proxies that traditional statistical math misses.

---

## ⚙️ System Architecture & Tech Stack
* **Frontend (Client):** HTML5, Vanilla JS, Chart.js, PapaParse. Parses massive CSVs instantly in the browser. Hosted on **Google Firebase** for secure, lightning-fast static edge delivery.
* **Backend (API):** Python, Flask. Handles routing and prompt engineering seamlessly. Hosted on **Koyeb** for dynamic execution.
* **Intelligence Engine:** **Google Gemini Flash API**. Provides the deep semantic world-knowledge required to flag nuanced demographic proxies.
* **MVP Cost:** $0.00 (Deployed entirely using serverless free tiers).

## 🔮 Future Development

We built Lexi-Fair AI to scale into a comprehensive enterprise compliance suite. Our immediate roadmap includes:

* **RAG (Retrieval-Augmented Generation) Integration:** Upgrading the system to connect Gemini to **Vertex AI Vector Search**. This will allow the UI to cite real-world legal precedents (e.g., GDPR, EU AI Act) when a demographic proxy is flagged.
* **Synthetic Data Generation:** Upgrading the "Quarantine" module. Instead of just masking or dropping a biased column, the system will use generative AI to create fair, synthetic rows—fixing demographic parity without sacrificing predictive data features.
* **Kaggle API Integration & Benchmarking:** Building a direct data pipeline via the Kaggle API to automatically fetch, benchmark, and open-source tests against real-world historical datasets (like loan defaults and hiring data) to continuously train and evaluate our ethics engine.
